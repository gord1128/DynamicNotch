📝 **주요 업데이트 요약 (v1.5.2)**

* **독(Dock) 숨김 처리**: 이제 앱이 독을 차지하지 않고 상단 메뉴바와 노치 공간에만 깔끔하게 상주합니다 (LSUIElement 적용).
* **노치 클릭 제스처 버그 수정**: 설정된 상호작용 방식(클릭, 길게 누르기)에 따라 짧게 탭할 때도 노치가 정상적으로 확장되도록 버그를 수정했습니다.
* **설정 번역 개선**: 캘린더 위젯 설정 내 어색했던 '상영 요일(Days to show)' 문구를 '표시할 기간'으로 자연스럽게 고쳤습니다.
* **자동화 로직 추가**: 저장소의 README 문서에 재밌는 뉴비 유머 템플릿과 상태를 추가했습니다.

⚠️ **서명되지 않은 앱 실행 안내**
보안 이슈로 '손상된 앱' 경고가 뜰 경우, 다운로드한 앱을 응용 프로그램(Applications) 폴더에 넣고 터미널에서 아래 명령어를 실행하세요.
`xattr -cr /Applications/DynamicNotch.app`
